# Часть 1. Задание 2.1 — одно нелинейное уравнение

## 1.1. Постановка задачи

*(ЛК-3, п. ①)*

Нужно решить уравнение **f(x) = 0**, то есть найти число x\*, при котором f(x\*) = 0.

Для нелинейных уравнений формулы корня, как правило, нет (для x⁴ − 2x − 1 = 0 её «школьным» способом не получить). Поэтому корень ищут **итерационно**: строят последовательность приближений

x⁰, x¹, x², …, xⁿ, …

так, чтобы она приближалась к x\*. Метод **сходится**, если lim xⁿ = x\* при n → ∞.

**Невязка** — насколько приближение не удовлетворяет уравнению: εⁿ = |f(xⁿ)|. Хотим, чтобы она уменьшалась от шага к шагу.

**Когда остановиться.** Точное x\* неизвестно, поэтому расстояние до него напрямую измерить нельзя. На практике (ЛК-3, стр. 2) останавливаются, когда соседние приближения почти совпали:

> **|xⁿ⁺¹ − xⁿ| < ε**

ε задаётся заранее (обычно 10⁻⁵ … 10⁻¹⁰); в программе это входной параметр.

**Решение идёт в две задачи** (ЛК-3, стр. 3):

1. **Отделение корня** — найти отрезок [a, b], на котором корень один.
2. **Уточнение корня** — найти его с точностью ε итерационным методом.

---

## 1.2. Отделение корня

*(ЛК-3, п. ②)*

### Теоремы

**Теорема 1.** Если f непрерывна на [a, b] и f(a)·f(b) < 0 (на концах разные знаки), то на [a, b] есть **хотя бы один** корень.

*Почему:* непрерывная функция не может перейти от минуса к плюсу, не пройдя через ноль.

**Теорема 2.** Если, кроме того, f дифференцируема и **f′(x) сохраняет знак** на [a, b], то корень **ровно один**.

*Почему:* если f′ > 0, функция строго возрастает и может пересечь ноль только один раз (при f′ < 0 — строго убывает).

### Графический способ

«Найти графически» — значит посмотреть на рисунок и на глаз определить, где лежит корень. Точное значение потом даёт метод, а график нужен, чтобы выбрать [a, b] и x⁰. Без этого метод может:
- сойтись к **другому** корню;
- **разойтись**.

Способа два (ЛК-3, стр. 2):

1. Построить y = f(x) и найти, где график пересекает ось Ox.
2. Разбить уравнение на две части и найти пересечение двух простых графиков.

### Разбор варианта 19

**Способ 1.** График y = x⁴ − 2x − 1 пересекает ось Ox в **двух точках**: около −0.47 и около 1.4. Значит, у уравнения два действительных корня, положительный — один.

**Способ 2.** x⁴ − 2x − 1 = 0 ⇔ **x⁴ = 2x + 1**. Строим параболу четвёртой степени y = x⁴ и прямую y = 2x + 1. Они пересекаются в тех же двух точках.

Оба графика — на вкладке «Графики» в окне 2.1 (верхний ряд).

**Выбор отрезка.** Положительная точка пересечения лежит между 1.3 и 1.4. Берём **[a, b] = [1.3, 1.4]**.

**Проверка теоремы 2:**

| | x = 1.3 | x = 1.4 |
|---|---|---|
| x⁴ | 2.8561 | 3.8416 |
| f(x) = x⁴ − 2x − 1 | **−0.7439** | **+0.0416** |

1. f(1.3)·f(1.4) < 0 — знаки разные ✓
2. f′(x) = 4x³ − 2. На [1.3, 1.4] выполняется x³ ≥ 1.3³ = 2.197, поэтому

   f′(x) ≥ 4·2.197 − 2 = **6.788 > 0** ✓

   (на конце 1.4: f′ = 4·2.744 − 2 = 8.976).

Вывод: на [1.3, 1.4] корень **ровно один**.

Заметим: |f(1.4)| = 0.04 ≪ |f(1.3)| = 0.74, значит корень ближе к 1.4. Это пригодится при выборе x⁰.

## 1.3. Метод половинного деления

*(ЛК-3, п. ③. В задании этого метода нет, но он есть в лекции, и о нём могут спросить.)*

Пусть f(a)·f(b) < 0. Отрезок сужают так:

1. Берут середину x¹ = (a + b)/2.
2. Смотрят, на какой половине функция меняет знак: f(a)·f(x¹) < 0 или f(x¹)·f(b) < 0.
3. Эту половину объявляют новым отрезком [a¹, b¹] и повторяют.

**Оценка погрешности:** после k шагов длина отрезка уменьшилась в 2ᵏ раз:

|x\* − xᵏ| ≤ (b − a)/2ᵏ.

Чтобы получить точность ε, нужно k ≥ log₂((b − a)/ε). Для [1.3, 1.4] и ε = 10⁻⁴ это k ≥ log₂(1000) ≈ 10 шагов.

**Недостаток:** метод медленный — каждый шаг даёт ровно один двоичный разряд (линейная сходимость). **Достоинство:** сходится всегда, если f(a)·f(b) < 0.

## 1.4. Метод простой итерации

*(ЛК-3, п. ④)*

### Идея

Уравнение f(x) = 0 приводят к **равносильному** виду

> **x = φ(x)**

и строят последовательность

> **xⁿ⁺¹ = φ(xⁿ)**.

Если последовательность сходится к x\* и φ непрерывна, то в пределе x\* = φ(x\*), то есть x\* — корень.

### Условие сходимости

> **|φ′(x)| < 1 для всех x ∈ [a, b]** — тогда процесс сходится к корню.

**Почему это работает** (короткое обоснование). По теореме Лагранжа о среднем

xⁿ⁺¹ − x\* = φ(xⁿ) − φ(x\*) = φ′(ξ)·(xⁿ − x\*), где ξ лежит между xⁿ и x\*.

Если |φ′| ≤ q < 1, то |xⁿ⁺¹ − x\*| ≤ q·|xⁿ − x\*|: **на каждом шаге расстояние до корня умножается не больше чем на q**. После n шагов погрешность не больше qⁿ·|x⁰ − x\*| → 0.

Отсюда же видно, что **чем меньше q, тем быстрее сходимость**. Такая сходимость называется линейной: погрешность убывает как геометрическая прогрессия.

### Геометрический смысл

*(ЛК-3, стр. 5–6)*

Корень — точка пересечения кривой y = φ(x) и прямой y = x. Шаг метода: из точки xⁿ поднимаемся до кривой, получаем φ(xⁿ), идём горизонтально до прямой y = x, получаем xⁿ⁺¹.

| Случай | Что происходит |
|---|---|
| 0 < φ′ < 1 | сходимость «лесенкой», с одной стороны от корня (рис. 1) |
| −1 < φ′ < 0 | сходимость «змейкой», приближения по разные стороны от корня (рис. 3) |
| \|φ′\| > 1 | приближения уходят от корня (рис. 2) |

### Как выбрать φ — главное в методе

Одно уравнение можно записать в виде x = φ(x) многими способами, и **сходятся не все**. В лекции для x³ − x + 1 = 0 показаны два способа: x = x³ + 1 и x = ∛(x − 1).

### Разбор варианта 19

**Способ 1.** Выражаем x из слагаемого 2x:

2x = x⁴ − 1 ⇒ **φ₁(x) = (x⁴ − 1)/2**, φ₁′(x) = 2x³.

На [1.3, 1.4] функция 2x³ возрастает: φ₁′(1.3) = 4.394, φ₁′(1.4) = 5.488. Получается **φ₁′ ≥ 4.39 > 1**, условие не выполнено. Это рис. 2: метод расходится.

Проверка на числах (6 итераций xⁿ⁺¹ = ((xⁿ)⁴ − 1)/2):

| n | от x⁰ = 1.4 | от x⁰ = 1.3 |
|---|---|---|
| 1 | 1.4208 | 0.92805 |
| 2 | 1.53752 | −0.1291 |
| 3 | 2.29417 | −0.49986 |
| 4 | 13.3507 | −0.46878 |
| 5 | 15884.4 | −0.47585 |
| 6 | 3.18·10¹⁶ | −0.47436 |

- От 1.4 приближения улетают в бесконечность.
- От 1.3 они сходятся к **отрицательному** корню ≈ −0.474: там |φ₁′| = 2·0.474³ ≈ 0.21 < 1, и видна «змейка» (−1 < φ₁′ < 0).

**Вывод:** условие сходимости зависит одновременно от φ и от отрезка.

**Способ 2.** Выражаем x из x⁴:

x⁴ = 2x + 1 ⇒ **φ₂(x) = ⁴√(2x + 1) = (2x + 1)^(1/4)**.

Производная (сложная функция):

φ₂′(x) = ¼·(2x + 1)^(−3/4)·2 = **½·(2x + 1)^(−3/4)**.

- φ₂′(1.3) = ½·3.6^(−3/4) ≈ **0.1913**
- φ₂′(1.4) = ½·3.8^(−3/4) ≈ **0.1837**

Показатель степени отрицательный, поэтому φ₂′ убывает, и максимум у неё на левом конце. Итого

**0 < φ₂′(x) ≤ 0.1913 < 1** на всём [1.3, 1.4] ✓

Это рис. 1: сходимость «лесенкой» с одной стороны. Берём **φ₂**.

> **Замечание про область определения.** φ₂ определена только при 2x + 1 ≥ 0, то есть x ≥ −0.5. В Python `(отрицательное) ** 0.25` для обычного числа **молча даёт комплексное число**, а для массива NumPy — `nan`. Поэтому программа проверяет, что каждое новое приближение лежит в [a, b], иначе останавливается с ошибкой.

**Первый шаг вручную** (x⁰ = 1.4): x¹ = (2·1.4 + 1)^(1/4) = 3.8^(1/4) = **1.396194**, |x¹ − x⁰| = 3.806·10⁻³.

## 1.5. Метод Ньютона

*(ЛК-3, п. ⑤–⑥)*

### Вывод формулы

Пусть xᵏ — текущее приближение. Разложим f в ряд Тейлора около xᵏ и оставим только линейную часть:

f(x) ≈ f(xᵏ) + f′(xᵏ)·(x − xᵏ).

Следующее приближение xᵏ⁺¹ ищем из условия, что эта линейная часть обращается в ноль:

f(xᵏ) + f′(xᵏ)·(xᵏ⁺¹ − xᵏ) = 0

Отсюда

> **xᵏ⁺¹ = xᵏ − f(xᵏ) / f′(xᵏ)**

### Геометрический смысл — метод касательных

*(ЛК-3, стр. 8)*

Линейная часть ряда Тейлора — это **касательная** к графику в точке (xᵏ, f(xᵏ)). xᵏ⁺¹ — точка пересечения касательной с осью Ox. Отсюда второе название метода.

Если f′(xᵏ) = 0, касательная горизонтальна и не пересекает ось: шаг сделать нельзя. Программа это проверяет.

### Ньютон как частный случай простой итерации

Формула Ньютона имеет вид xᵏ⁺¹ = φ(xᵏ) с

> **φ(x) = x − f(x)/f′(x)**.

Значит, к нему подходит то же условие сходимости |φ′(x)| < 1. Найдём φ′ по формуле производной частного:

φ′(x) = 1 − [f′·f′ − f·f″] / (f′)² = 1 − 1 + f·f″/(f′)²

> **φ′(x) = f(x)·f″(x) / (f′(x))²** — формула из лекции.

### Почему Ньютон сходится так быстро

В корне f(x\*) = 0, значит **φ′(x\*) = 0**. Около корня множитель q, на который умножается погрешность, стремится к нулю. Поэтому сходимость гораздо быстрее линейной: погрешность на следующем шаге примерно пропорциональна **квадрату** текущей,

|xᵏ⁺¹ − x\*| ≈ C·|xᵏ − x\*|².

На практике это значит, что число верных знаков на каждом шаге примерно удваивается. *(Термин «квадратичная сходимость» в ЛК-3 не записан, но следует из φ′(x\*) = 0.)*

### Модификации

*(ЛК-3, п. ⑥)*

Если касательная пологая, шаг Ньютона может «выстрелить» далеко за отрезок [a, b]. Модификации:

1. **Коэффициент шага:** xᵏ⁺¹ = xᵏ − α·f(xᵏ)/f′(xᵏ), |α| < 1. α подбирают так, чтобы остаться на [a, b].
2. **Ньютон + половинное деление:** если xᵏ⁺¹ > b, берут (xᵏ + b)/2; если xᵏ⁺¹ < a, берут (xᵏ + a)/2.

В программе модификации не реализованы: при выходе за [a, b] метод останавливается с ошибкой.

### Разбор варианта 19

f(x) = x⁴ − 2x − 1, f′(x) = 4x³ − 2, **f″(x) = 12x²**.

**Условие сходимости на концах отрезка:**

| x | f | f″ | (f′)² | φ′ = f·f″/(f′)² |
|---|---|---|---|---|
| 1.3 | −0.7439 | 20.28 | 46.08 | **−0.3274** |
| 1.4 | 0.0416 | 23.52 | 80.57 | **0.0121** |

**Оценка на всём отрезке.** Каждый множитель берём в худшем для нас случае:
- |f| ≤ 0.7439, так как f возрастает и наибольший модуль у неё на конце 1.3;
- f″ ≤ 12·1.4² = 23.52;
- (f′)² ≥ 6.788² = 46.08.

Получаем |φ′(x)| ≤ 0.7439·23.52/46.08 ≈ **0.38 < 1** ✓

**Выбор x⁰ = 1.4**, а не 1.3:

1. Там |φ′| ≈ 0.012, а не 0.33.
2. На конце 1.4 f > 0 и f″ > 0 (функция выпукла вниз). Касательные, проведённые справа от корня, подходят к нему с одной стороны и не выскакивают из отрезка, как на рисунке ЛК-3, стр. 8.

**Проверка:** из x⁰ = 1.3 первый же шаг даёт x¹ = 1.4096 > 1.4, приближение вышло из отрезка. Это ровно та ситуация, о которой говорит п. ⑥. Можно показать в окне: поставить x⁰ = 1.3 и нажать «Решить».

**Первый шаг вручную** (x⁰ = 1.4): f(1.4) = 0.0416, f′(1.4) = 8.976,

x¹ = 1.4 − 0.0416/8.976 = **1.395365**.

## 1.6. Результаты и анализ погрешности

ε = 10⁻⁴, [a, b] = [1.3, 1.4], x⁰ = 1.4.

**Простая итерация:**

| k | xᵏ | \|xᵏ − xᵏ⁻¹\| |
|---|---|---|
| 1 | 1.396194423768 | 3.806·10⁻³ |
| 2 | 1.395494776423 | 6.996·10⁻⁴ |
| 3 | 1.395366033119 | 1.287·10⁻⁴ |
| 4 | 1.395342338962 | 2.369·10⁻⁵ |

**Ньютон:**

| k | xᵏ | \|xᵏ − xᵏ⁻¹\| |
|---|---|---|
| 1 | 1.395365418895 | 4.635·10⁻³ |
| 2 | 1.395336995531 | 2.842·10⁻⁵ |

**Итог:**

| Метод | x | итераций | невязка \|f(x)\| |
|---|---|---|---|
| Простая итерация | 1.395342 | 4 | 4.7·10⁻⁵ |
| Ньютон | 1.395337 | 2 | 9.4·10⁻⁹ |

**Число итераций в зависимости от ε:**

| ε | Простая итерация | Ньютон |
|---|---|---|
| 10⁻¹ | 1 | 1 |
| 10⁻² | 1 | 1 |
| 10⁻³ | 2 | 2 |
| 10⁻⁴ | 4 | 2 |
| 10⁻⁵ | 5 | 3 |
| 10⁻⁶ | 6 | 3 |
| 10⁻⁸ | 9 | 3 |
| 10⁻¹⁰ | 12 | 4 |

### Анализ — что говорить на сдаче

1. **Простая итерация: погрешность убывает как геометрическая прогрессия.** Отношение соседних погрешностей примерно постоянно:

   6.996·10⁻⁴ / 3.806·10⁻³ ≈ 0.184, 1.287·10⁻⁴ / 6.996·10⁻⁴ ≈ 0.184, …

   Это ровно φ₂′(x\*) = ½·(2·1.3953 + 1)^(−3/4) ≈ **0.184**. Теория из п. 1.4 подтверждается: на каждом шаге погрешность умножается на φ′. На графике с логарифмической осью y это **прямая линия**.

2. **Число итераций простой итерации растёт линейно с числом знаков.** При уменьшении ε в 10 раз добавляется 1–2 итерации, потому что 0.184ᵏ = 0.1 при k ≈ 1.4. От 10⁻⁴ до 10⁻¹⁰ (6 порядков) добавилось 8 итераций.

3. **Ньютон: число верных знаков удваивается.** Погрешность 4.6·10⁻³ превратилась в 2.8·10⁻⁵ ≈ 1.3·(4.6·10⁻³)². На графике это **круто падающая кривая**, а не прямая.

4. **У Ньютона число итераций почти не зависит от ε:** 3–4 итерации от 10⁻⁵ до 10⁻¹⁰.

5. **Цена шага.** Ньютону на каждом шаге нужна производная f′(x). Простая итерация дешевле, но шагов ей нужно больше. Для такого простого уравнения это неважно, а для систем (часть 2) Ньютон дороже заметно: на каждом шаге нужно решать линейную систему.

6. **Невязка** у Ньютона на 4 порядка меньше при том же ε. Критерий |xᵏ − xᵏ⁻¹| < ε у него срабатывает «с запасом»: после последнего шага погрешность уже около квадрата ε.

# Часть 2. Задание 2.2 — система нелинейных уравнений

## 2.1. Постановка задачи

*(ЛК-3, п. ⑦)*

Система n уравнений с n неизвестными:

f₁(x₁, …, xₙ) = 0,
f₂(x₁, …, xₙ) = 0,
…
fₙ(x₁, …, xₙ) = 0.

В векторной записи **F(x) = 0**, где x = (x₁, …, xₙ)ᵀ и F = (f₁, …, fₙ)ᵀ.

Всё то же, что в части 1, только вместо чисел векторы:

| Одно уравнение | Система |
|---|---|
| x — число | x — вектор |
| \|xᵏ⁺¹ − xᵏ\| | ‖xᵏ⁺¹ − xᵏ‖ — норма вектора |
| отрезок [a, b] | область G (у нас прямоугольник) |
| f′(x) | матрица Якоби J(x) |
| φ′(x) | матрица производных φ′(x) |
| \|φ′\| < 1 | ‖φ′‖ < 1 |

**Норма.** Используем ту же норму, что в ЛР 1.3:

- вектора: ‖v‖ = max |vᵢ| (наибольший по модулю элемент);
- матрицы: ‖M‖ = max по строкам Σⱼ |mᵢⱼ| (наибольшая сумма модулей в строке).

Эти нормы **согласованы**: ‖Mv‖ ≤ ‖M‖·‖v‖. Это и позволяет переносить на системы доказательства из части 1.

## 2.2. Исследование системы варианта 19

a = 1:

> f₁(x₁, x₂) = x₁² − 2·lg x₂ − 1 = 0
> f₂(x₁, x₂) = x₁² − x₁x₂ + 1 = 0

**Область определения:** lg x₂ существует только при **x₂ > 0**.

В задании сказано: «при наличии нескольких решений найти то, в котором неизвестные положительны». Сначала выясним, сколько решений вообще. (Этот анализ необязателен, но на сдаче выглядит очень убедительно.)

**Шаг 1. Из f₂ выражаем x₂.** При x₁ = 0 уравнение даёт 0 − 0 + 1 = 1 ≠ 0, значит x₁ ≠ 0, и можно делить:

x₁x₂ = x₁² + 1 ⇒ **x₂ = x₁ + 1/x₁**.

**Шаг 2. Знак x₁.** Если x₁ < 0, то x₁ + 1/x₁ < 0, то есть x₂ < 0, а это запрещено логарифмом. Значит, **x₁ > 0**, и тогда x₂ = x₁ + 1/x₁ ≥ 2: сумма положительного числа и обратного к нему не меньше 2. Получается, что **у любого решения обе координаты положительны**.

**Шаг 3. Подставляем в f₁.** Получаем одно уравнение относительно x₁:

g(x₁) = x₁² − 1 − 2·lg(x₁ + 1/x₁) = 0, x₁ > 0.

- g(1) = 1 − 1 − 2·lg 2 = −0.602 < 0
- g(1.5) = 2.25 − 1 − 2·lg 2.1667 = 0.578 > 0

**Шаг 4. g строго возрастает при x₁ > 0**, поэтому корень у неё один:

g′(x₁) = 2x₁ − (2/ln 10)·(x₁² − 1) / (x₁(x₁² + 1)).

- При x₁ ≤ 1 вычитаемое ≤ 0, поэтому g′ ≥ 2x₁ > 0.
- При x₁ > 1 справедливо (x₁² − 1)/(x₁² + 1) < 1, поэтому вычитаемое меньше 2/(x₁ ln 10) < 0.87, а 2x₁ > 2. Снова g′ > 0.

**Вывод:** система имеет **ровно одно решение**, и оно положительное. Именно его и ищем.

Решение системы двух уравнений — **точка пересечения двух кривых** f₁ = 0 и f₂ = 0 на плоскости (x₁, x₂).

## 2.4. Метод Ньютона для систем

*(ЛК-3, стр. 10)*

### Матрица Якоби

**Матрица Якоби** — матрица частных производных. В строке i стоят производные функции fᵢ по всем переменным:

```
        ⎛ ∂f₁/∂x₁  …  ∂f₁/∂xₙ ⎞
J(x) =  ⎜    ⋮      ⋱     ⋮    ⎟
        ⎝ ∂fₙ/∂x₁  …  ∂fₙ/∂xₙ ⎠
```

Это многомерный аналог производной f′(x).

### Вывод формулы

Точно как в п. 1.5, только для векторов. Линеаризуем F около xᵏ:

F(x) ≈ F(xᵏ) + J(xᵏ)·(x − xᵏ)

и приравниваем нулю:

F(xᵏ) + J(xᵏ)·(xᵏ⁺¹ − xᵏ) = 0.

Отсюда

> **xᵏ⁺¹ = xᵏ − J⁻¹(xᵏ)·F(xᵏ)**, k = 0, 1, 2, …

Сравни с одномерным случаем: xᵏ⁺¹ = xᵏ − f(xᵏ)/f′(xᵏ). Деление на f′ превратилось в умножение на обратную матрицу J⁻¹.

### Как это считать на практике

Обратную матрицу на каждом шаге **не вычисляют**: это в n раз дороже и теряет точность. Вместо этого обозначают Δx = xᵏ⁺¹ − xᵏ и решают **линейную систему**

> **J(xᵏ)·Δx = −F(xᵏ)**, затем **xᵏ⁺¹ = xᵏ + Δx**.

Это та же формула, просто без явного J⁻¹. В программе линейная система решается **нашим LU-разложением из ЛР 1.1** (функции `LU` и `solve_lu` из `lab1_1/lu.py`, с выбором опорного элемента). Готовый `np.linalg.solve` по требованиям ЛР использовать нельзя.

Методу нужно, чтобы **det J(xᵏ) ≠ 0** на каждом шаге. Иначе линейная система не решается, а это многомерный аналог f′(x) = 0. `LU` сам сообщает о вырожденной матрице.

### Критерий остановки

*(ЛК-3, стр. 10)*

‖xᵏ⁺¹ − xᵏ‖ < ε; у нас это ‖Δx‖ < ε.

В лекции указан и равноценный критерий по невязке |fᵢ(x)| < εᵢ. Программа выводит невязку ‖F(x)‖ в итоговой таблице.

### Демпфированный метод

*(ЛК-3, стр. 10)*

xᵏ⁺¹ = xᵏ − α·J⁻¹(xᵏ)·F(xᵏ), 0 < α < 1. Аналог «коэффициента шага» из п. 1.5: меньший шаг, чтобы не выскочить из области.

### Разбор варианта 19

**Частные производные.** При дифференцировании по одной переменной другая считается константой. Помним, что (lg x)′ = 1/(x·ln 10).

| | ∂/∂x₁ | ∂/∂x₂ |
|---|---|---|
| f₁ = x₁² − 2 lg x₂ − 1 | 2x₁ | −2/(x₂·ln 10) |
| f₂ = x₁² − a·x₁x₂ + a | 2x₁ − a·x₂ | −a·x₁ |

```
        ⎛ 2x₁           −2 / (x₂ ln 10) ⎞
J(x) =  ⎝ 2x₁ − a·x₂    −a·x₁           ⎠
```

**Первый шаг вручную** (x⁰ = (1.3, 2.1), a = 1). Его стоит пересчитать на листочке.

1. Значения функций:
   - lg 2.1 = 0.322219
   - f₁ = 1.69 − 2·0.322219 − 1 = **0.045561**
   - f₂ = 1.69 − 1.3·2.1 + 1 = 1.69 − 2.73 + 1 = **−0.04**
2. Матрица Якоби:
   - ∂f₁/∂x₁ = 2·1.3 = 2.6
   - ∂f₁/∂x₂ = −2/(2.1·2.302585) = −0.413614
   - ∂f₂/∂x₁ = 2.6 − 2.1 = 0.5
   - ∂f₂/∂x₂ = −1.3

   ```
   J(x⁰) = ⎛ 2.6   −0.413614 ⎞
           ⎝ 0.5   −1.3      ⎠
   ```
   det J = 2.6·(−1.3) − (−0.413614)·0.5 = −3.38 + 0.206807 = **−3.173193 ≠ 0** ✓
3. Решаем J·Δx = −F = (−0.045561, 0.04). Для 2×2 на листочке удобно по Крамеру (программа делает это через LU):
   - Δx₁ = [(−0.045561)·(−1.3) − (−0.413614)·0.04] / det = (0.059230 + 0.016545)/(−3.173193) = **−0.023880**

4. x¹ = x⁰ + Δx = (1.3 − 0.023880, 2.1 − 0.039954) = **(1.276120, 2.060046)**

   ‖Δx‖ = max(0.023880, 0.039954) = 3.995·10⁻². Совпадает с первой строкой таблицы в программе.

## 2.5. Метод простой итерации для систем

> ⚠ **не из ЛК-3.** В ЛК-3 для систем записан только метод Ньютона. Ниже — прямой перенос простой итерации из п. 1.4 на векторы, по той же схеме, что метод простых итераций для линейных систем в ЛК-2 (там x = αx + β и условие ‖α‖ < 1). Теорема о сходимости — стандартная, из учебников по численным методам.

### Идея

Систему F(x) = 0 приводят к виду

> **x = φ(x)**, то есть xᵢ = φᵢ(x₁, …, xₙ), i = 1, …, n,

и строят **x⁽ᵏ⁺¹⁾ = φ(x⁽ᵏ⁾)**.

Для линейной системы из ЛР 1.3 φ(x) = αx + β, и «производная» φ — это просто матрица α. Для нелинейной системы роль α играет **матрица производных**

```
         ⎛ ∂φ₁/∂x₁  …  ∂φ₁/∂xₙ ⎞
φ′(x) =  ⎜    ⋮      ⋱     ⋮    ⎟
         ⎝ ∂φₙ/∂x₁  …  ∂φₙ/∂xₙ ⎠
```

Это матрица Якоби функции φ. Она меняется от точки к точке.

### Условие сходимости

**Теорема.** Пусть G — замкнутая область и

1. **φ(G) ⊂ G** — φ переводит точки из G снова в G (итерации не выходят из области);
2. **q = max по x ∈ G ‖φ′(x)‖ < 1**.

Тогда в G есть единственное решение, и итерации сходятся к нему **при любом x⁽⁰⁾ ∈ G**.

Почему так, коротко: по многомерному аналогу теоремы Лагранжа ‖φ(x) − φ(y)‖ ≤ q·‖x − y‖, поэтому расстояние до решения на каждом шаге умножается не больше чем на q. Это то же рассуждение, что в п. 1.4. Условие 1 нужно, чтобы оценку можно было применять снова и снова.

В одномерном случае (часть 1) условие 1 тоже на самом деле нужно, просто для нашего φ₂ оно выполнялось само: φ₂([1.3, 1.4]) = [3.6^(1/4), 3.8^(1/4)] = [1.3774, 1.3962] ⊂ [1.3, 1.4].

**Оценка погрешности** (как в ЛР 1.3): ‖x⁽ᵏ⁾ − x\*‖ ≤ q/(1 − q) · ‖x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾‖. В программе останавливаемся по ‖x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾‖ < ε, как указано в ЛК-3, и для обоих методов одинаково. При q ≈ 0.49 множитель q/(1 − q) ≈ 0.96 < 1, так что настоящая погрешность даже меньше ε.

### Разбор варианта 19: выбор φ

Нужно из каждого уравнения выразить «свою» переменную.

**Удачный способ (используется в программе).**

- Из f₁: x₁² = 1 + 2 lg x₂ ⇒ **φ₁(x) = √(1 + 2·lg x₂)**. Берём корень с плюсом, потому что x₁ > 0.
- Из f₂: a·x₁x₂ = x₁² + a ⇒ **φ₂(x) = x₁/a + 1/x₁** (при a = 1: x₁ + 1/x₁).

Матрица производных:

| | ∂/∂x₁ | ∂/∂x₂ |
|---|---|---|
| φ₁ = √(1 + 2 lg x₂) | 0 | 1 / (x₂·ln 10·√(1 + 2 lg x₂)) |
| φ₂ = x₁/a + 1/x₁ | 1/a − 1/x₁² | 0 |

Как получена производная φ₁ по x₂: (√u)′ = u′/(2√u), u = 1 + 2 lg x₂, u′ = 2/(x₂ ln 10), отсюда 2/(x₂ ln 10)/(2√u) = 1/(x₂ ln 10 √u).

В каждой строке один ненулевой элемент, поэтому

‖φ′(x)‖ = max( |∂φ₁/∂x₂|, |∂φ₂/∂x₁| ).

**Проверка условия 2 на G = [1.2, 1.4] × [2.0, 2.2]:**

- |∂φ₁/∂x₂| убывает по x₂, так как x₂ стоит в знаменателе. Максимум при x₂ = 2.0:

  1/(2.0·2.302585·√(1 + 2·0.30103)) = 1/(4.60517·1.26573) = **0.1716**
- ∂φ₂/∂x₁ = 1 − 1/x₁² возрастает по x₁. Максимум при x₁ = 1.4:

  1 − 1/1.96 = **0.4898**

**q = 0.4898 < 1** ✓

**Проверка условия 1, φ(G) ⊂ G:**

- φ₁ зависит только от x₂ и возрастает. При x₂ ∈ [2.0, 2.2]:

  φ₁ ∈ [√(1 + 2 lg 2.0), √(1 + 2 lg 2.2)] = [1.2657, 1.2980] ⊂ [1.2, 1.4] ✓
- φ₂ зависит только от x₁ и возрастает при x₁ > 1. При x₁ ∈ [1.2, 1.4]:

  φ₂ ∈ [1.2 + 1/1.2, 1.4 + 1/1.4] = [2.0333, 2.1143] ⊂ [2.0, 2.2] ✓

Оба условия выполнены: итерации сходятся при любом x⁰ ∈ G. Программа проверяет то же самое **по сетке 101 × 101 точек** в G и выводит q и диапазоны φ(G).

**Неудачный способ (для сравнения).** Выразим переменные «наоборот»:

- из f₂: x₁ = √(x₁x₂ − 1);
- из f₁: x₂ = 10^((x₁² − 1)/2).

Производная второй функции ∂φ₂/∂x₁ = ln 10 · x₁ · 10^((x₁² − 1)/2) в точке решения равна **6.05 > 1**. Условие нарушено.

Проверка на числах от x⁰ = (1.3, 2.1): (1.315, 2.213), (1.382, 2.317), (1.484, 2.854), (1.799, 3.997), (2.488, 13.13), (5.63, 393.6), … — **расходится**.

Мораль та же, что в части 1: **сходимость определяется выбором φ**.

**Первый шаг вручную** (x⁰ = (1.3, 2.1)):

- x₁¹ = √(1 + 2·0.322219) = √1.644439 = **1.282357**
- x₂¹ = 1.3 + 1/1.3 = **2.069231**
- ‖x¹ − x⁰‖ = max(0.017643, 0.030769) = 3.077·10⁻²

Для n = 2 разница несущественна. Для больших систем решение линейной системы стоит порядка n³ операций на шаг, и это становится важно.

5. **Чувствительность к x⁰.** Если взять область пошире, G = [0.1, 2.5] × [0.1, 4]:
   - от x⁰ = (2.0, 3.5) сходятся оба метода (8 и 5 итераций);
   - от x⁰ = (0.5, 1.0) простая итерация сходится за 9 итераций, а **Ньютон на первом же шаге выскакивает из области**, в точку (2.55, 2.5).

   Это иллюстрация того, что Ньютон сходится только из достаточно хорошего начального приближения, и того, зачем нужен график.

## Методы — что важно уметь объяснить

Обе версии (2.1 и 2.2) устроены одинаково:

```
history = []
x = x⁰
повторять не более MAX_ITERATIONS раз:
    x_new = формула метода(x)
    если x_new вне [a, b] (или G) → ошибка ValueError
    error = |x_new − x|     (для систем — норма)
    добавить (x_new, error) в history
    если error < ε → вернуть (x_new, history)
    x = x_new
ошибка «не сошёлся»
```

- **`MAX_ITERATIONS = 1000`** защищает от бесконечного цикла, если метод расходится.
- **Проверка [a, b] / G.** Условия сходимости проверены только там. Кроме того, вне области φ может быть не определена: корень из отрицательного числа или lg x₂ при x₂ ≤ 0.
- **`history`** — список пар (xᵏ, погрешность). По нему строятся таблица итераций и график погрешности, а `len(history)` — это число итераций.
- **Методы принимают функции как аргументы** (`fi`, `f`, `df` или `phi`, `F`, `J`). Поэтому код методов не зависит от варианта: чтобы решить другое уравнение, достаточно поменять `functions.py`.
- **Методы для систем работают при любом n.** Векторы — массивы NumPy, норма — по всем компонентам, линейная система решается LU-разложением n × n. Это требование 4 к ЛР (универсальность).

**Ньютон для систем, ключевые строки** (`lab2_2/system_methods.py`):

```python
L, U, perm, _ = LU(J(x))            # LU-разложение матрицы Якоби (ЛР 1.1)
dx = solve_lu(L, U, perm, -F(x))    # решаем J·dx = −F(x)
x_new = x + dx                      # то же, что x − J⁻¹F(x)
```

Если `LU` обнаружил вырожденную матрицу (нулевой опорный элемент), он бросает `ValueError`. Мы перехватываем её и сообщаем, что матрица Якоби вырождена.

# Часть 4. Вопросы на сдаче

**Общие**

1. *Что такое невязка?* — |f(xⁿ)| (для систем ‖F(xⁿ)‖): насколько приближение не удовлетворяет уравнению.
2. *Почему останавливаемся по |xⁿ⁺¹ − xⁿ| < ε, а не по |xⁿ − x\*|?* — x\* неизвестно. Когда шаги стали меньше ε, приближения практически перестали меняться.
3. *Зачем начальное приближение определять графически?* — Чтобы метод сошёлся и сошёлся к нужному корню. Пример: φ₁ из x⁰ = 1.3 сошлась к отрицательному корню; Ньютон из x⁰ = 1.3 выскочил из отрезка.
4. *Сформулируйте теоремы 1 и 2.* — См. п. 1.2. Для варианта: f(1.3) = −0.7439, f(1.4) = 0.0416, f′ ≥ 6.788 > 0.

**Простая итерация**

5. *Условие сходимости?* — |φ′(x)| < 1 на [a, b]. Для систем ‖φ′(x)‖ < 1 в G и φ(G) ⊂ G.
6. *Почему именно < 1?* — По теореме Лагранжа погрешность на каждом шаге умножается на |φ′(ξ)|. Если множитель меньше 1, она стремится к нулю.
7. *Почему вы выбрали φ(x) = ⁴√(2x + 1), а не (x⁴ − 1)/2?* — У второй φ′ = 2x³ ≥ 4.39 > 1, метод расходится (числа в п. 1.4).
8. *Что такое «лесенка» и «змейка»?* — Сходимость при 0 < φ′ < 1 (с одной стороны от корня) и при −1 < φ′ < 0 (с разных сторон).
9. *От чего зависит скорость сходимости?* — От величины |φ′| около корня. У нас ≈ 0.184, ровно во столько раз уменьшается погрешность за шаг (видно в таблице).

**Ньютон**

10. *Выведите формулу метода Ньютона.* — Линеаризация f по Тейлору, приравниваем к нулю (п. 1.5).
11. *Геометрический смысл?* — Пересечение касательной с осью Ox.
12. *Почему Ньютон — частный случай простой итерации? Чему равно φ′?* — φ = x − f/f′, φ′ = f·f″/(f′)² (вывод в п. 1.5).
13. *Почему Ньютон быстрее?* — φ′(x\*) = 0, так как f(x\*) = 0. Погрешность примерно возводится в квадрат на каждом шаге, число верных знаков удваивается.
14. *Почему x⁰ = 1.4, а не 1.3?* — Там |φ′| = 0.012 против 0.33. Справа от корня f > 0 и f″ > 0, касательные не выскакивают из отрезка. Из 1.3 первый шаг даёт 1.4096 > b.
15. *Что делать, если шаг Ньютона выводит из отрезка?* — Модификации п. ⑥: коэффициент α или половинное деление (xᵏ + b)/2.
16. *Что будет, если f′(xᵏ) = 0?* — Касательная горизонтальна, шаг невозможен. Программа сообщает об ошибке.

**Системы**

17. *Что такое матрица Якоби? Выпишите её для своей системы.* — Матрица частных производных (п. 2.4).
18. *Как вы вычисляете J⁻¹?* — Не вычисляю. Решаю линейную систему J·Δx = −F своим LU-разложением из ЛР 1.1 и беру x + Δx. Это эквивалентно и дешевле.
19. *Какое условие нужно для метода Ньютона в системах?* — det J(xᵏ) ≠ 0. У нас det J(x⁰) = −3.17.
20. *Как вы привели систему к виду x = φ(x) и как проверили сходимость?* — φ₁ = √(1 + 2 lg x₂), φ₂ = x₁ + 1/x₁; q = 0.49 < 1, φ(G) ⊂ G (п. 2.5).
21. *Сколько решений у системы? Почему именно положительное?* — Одно, и оно положительное (п. 2.2). Из f₂ получаем x₂ = x₁ + 1/x₁; из lg x₂ следует x₂ > 0, отсюда x₁ > 0; g(x₁) строго возрастает.
22. *Какой нормой вы пользуетесь?* — Максимум модуля для векторов, максимум суммы модулей по строкам для матриц. Они согласованы, как в ЛР 1.3.
23. *Почему фактическая скорость простой итерации (~0.25) лучше, чем q = 0.49?* — q — оценка по всей области, худший случай. Около решения производные меньше (п. 2.6).

**Код**

24. *Зачем `MAX_ITERATIONS`?* — Защита от бесконечного цикла, если метод расходится.
25. *Зачем проверка, что приближение в [a, b] / G?* — Условия сходимости проверены только там, а вне области функции могут быть не определены (корень, логарифм).
26. *Как программа проверяет условия сходимости?* — Находит максимум |φ′| (‖φ′‖) по сетке точек на отрезке / в области. Это приближённая проверка; аналитическая — в этом конспекте.
27. *Будет ли программа работать для другой системы большей размерности?* — Методы — да: они работают с векторами любой длины и с LU n × n. Для другой системы нужно переписать `system_functions.py` (F, J, φ, φ′) и `N`.
