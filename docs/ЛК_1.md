## ① Метод Гаусса

Метод Гаусса позволяет решить любую задачу, но за O(n³).
Для большой матрицы данный алгоритм не подходит, поэтому мы рассматриваем частные случаи матриц.

**Например:** трёхдиагональная матрица.

На рисунке: матрица, у которой крестиками отмечены ненулевые элементы на трёх диагоналях (главной и двух соседних), а в остальных местах (левый нижний и правый верхний углы) стоят нули. «О — нулевые элементы, × (крестик) — ненулевые элементы». Подпись: «3 диагонали».

## Метод прогонки для решения систем линейных уравнений с трёхдиагональной матрицей

1. Приведение трёхдиагональной матрицы к верхней треугольной (прямой ход) → приведение к двухдиагональной → во всех уравнениях, кроме последнего, две неизвестные, в последнем одна.
2. Запись обратного хода в виде xᵢ = Pᵢ₊₁ xᵢ₊₁ + Qᵢ₊₁.
3. Вывод рекуррентного соотношения для Pᵢ₊₁ и Qᵢ₊₁ через Pᵢ и Qᵢ и получение соотношения для P₂ и Q₂ (P₁ = Q₁ = 0).
4. Осуществление обратного хода метода прогонки и определение всех неизвестных.

Запишем СЛАУ в виде:

  aᵢ xᵢ₋₁ − bᵢ xᵢ + cᵢ xᵢ₊₁ = dᵢ,  i = 1, 2, …, n   (\*)

  a₁ = cₙ = 0

← Канонический вид системы линейных уравнений метода прогонки.

Матрица системы:

```
      ( −b₁   c₁   0    0   …   0     0  )
      ( a₂   −b₂   c₂   0   …   0     0  )
A  =  ( 0    a₃   −b₃   c₃  …   0     0  )
      ( …                                )
      ( 0    0    0    0   …  −bₙ₋₁  cₙ₋₁)
      ( 0    0    0    0   …   aₙ    −bₙ )
```

(элементы a₂, a₃, …, aₙ на скане обведены в рамки)

Минус у переменной b мы поставили для удобства. Это упрощает формулы метода прогонки.

Прямой ход сводится к исключению неизвестного **xᵢ₋₁** в каждом уравнении системы.

i-ая строка преобразованной двухдиагональной матрицы:

  xᵢ = Pᵢ₊₁ xᵢ₊₁ + Qᵢ₊₁

  ↓

  xᵢ₋₁ = Pᵢ xᵢ + Qᵢ

Подставим в (\*), получим

  aᵢ (Pᵢ xᵢ + Qᵢ) − bᵢ xᵢ + cᵢ xᵢ₊₁ = dᵢ

  ↓

  xᵢ = [bᵢ − aᵢPᵢ]⁻¹ cᵢ xᵢ₊₁ + [bᵢ − aᵢPᵢ]⁻¹ [ … ]

(на скане выражение в конце оборвано; стрелка «сравниваем» связывает эту формулу с записью xᵢ = Pᵢ₊₁ xᵢ₊₁ + Qᵢ₊₁) ⚠

Запишем рекуррентное соотношение:

  Pᵢ₊₁ = cᵢ [bᵢ − aᵢPᵢ]⁻¹,
  Qᵢ₊₁ = [aᵢQᵢ − dᵢ] [bᵢ − aᵢPᵢ]⁻¹

— **прогоночные коэффициенты**.

Для начала прямого метода прогонки необходимо задать начальные (стартовые) значения прогоночных коэффициентов, например P₁ и Q₁.

Но P₂ = c₁/b₁ и Q₂ = −d₁/b₁, поэтому P₁ и Q₁ можно задать любые, например P₁ = 0 и Q₁ = 0.

Аналогично зададим xₙ₊₁ = 0
  ↓
  xₙ = Qₙ₊₁

Метод прогонки корректен, если bᵢ − aᵢPᵢ ≠ 0.

**Условие устойчивости матричной прогонки:**

  |det Pᵢ| < 1

**Условие корректности и устойчивости:**

  det(Bᵢ⁻¹Cᵢ) + det(Bᵢ⁻¹Aᵢ) < 1   ⚠ (так записано в конспекте)

## ② Метод простых итераций (МПИ)

СЛАУ приводится к эквивалентному виду

  x = αx + β   (\*\*)

  α ∈ ℝⁿˣⁿ, β ∈ ℝⁿ

Решение этой системы как предел последовательности векторов при k → ∞:

  x⁽ᵏ⁺¹⁾ = αx⁽ᵏ⁾ + β,  k = 0, 1, 2, …

где x⁽⁰⁾ — начальное приближение для вектора решения.

### Этапы осуществления итерационного метода

1. Построение для вычисления последовательных приближений итерационного процесса, сходящегося к точному решению (т.е. построение последовательности векторов x⁽⁰⁾, x⁽¹⁾, x⁽²⁾, …, x⁽ᵏ⁾, сходящейся к точному решению x\*).
2. Определение критерия сходимости этого процесса, позволяющего определить момент достижения требуемой точности.
3. Исследование скорости сходимости и оптимизация итерационного процесса с целью уменьшения числа операций, необходимых для достижения требуемой точности.

### Норма матрицы

**Норма матрицы** — это число, которое характеризует «размер» или «величину» матрицы, аналогично тому, как норма вектора характеризует длину вектора.

**Нормой** называется вещественное неотрицательное число, удовлетворяющее следующим условиям:

1. ‖x‖ > 0 при x ≠ 0, ‖x‖ = 0 при x = 0
2. ‖αx‖ = |α| ‖x‖
3. ‖x + y‖ = ‖x‖ + ‖y‖   ⚠ (в конспекте записано со знаком «=»)

**В n-мерном пространстве**, элементами которого являются группы из n чисел x = {x₁, x₂, …, xₙ}, **норма определена**

  ‖x‖ = [ (1/n) Σⱼ₌₁ⁿ |xᵢ|ᵖ ]^(1/p)   ⚠ (индексы суммирования записаны как j и i)

### Нормы в пространстве квадратных матриц порядка n

1. Максимальное число среди сумм модулей элементов строк матрицы

  ‖A‖ₑ = maxᵢ [ Σⱼ₌₁ⁿ |aᵢⱼ| ]

2. Максимальное число среди сумм модулей элементов столбцов матрицы

  ‖A‖₁ = maxⱼ [ Σᵢ₌₁ⁿ |aᵢⱼ| ]

3. Максимальная норма

  ‖A‖ₘ = n · maxᵢ,ⱼ |aᵢⱼ|

4. Евклидова (сферическая) норма

  ‖A‖ᴇ = [ Σᵢ,ⱼ₌₁ⁿ |aᵢⱼ|² ]^(1/2)

### Теорема (достаточное условие сходимости метода простой итерации)

Если какая-либо норма матрицы α, согласованная с рассматриваемой нормой вектора x, меньше единицы (‖α‖ < 1), то последовательность x⁽ᵏ⁾ в методе простой итерации сходится к точному решению x\* системы (\*\*) со скоростью, не меньшей скорости геометрической прогрессии со знаменателем q ≤ ‖α‖ при любом начальном приближении x⁽⁰⁾.

**Док-во.** ▶ Погрешность ε⁽ᵏ⁾ = x\* − x⁽ᵏ⁾

  x\* = αx\* + β
  −
  x⁽ᵏ⁺¹⁾ = αx⁽ᵏ⁾ + β
  ‖
  ε⁽ᵏ⁺¹⁾ = αε⁽ᵏ⁾

Переходя к нормам, имеем

  ‖ε⁽ᵏ⁾‖ = ‖αᵏ ε⁽⁰⁾‖ ≤ ‖αᵏ‖ · ‖ε⁽⁰⁾‖ ≤ ‖α‖ᵏ · ‖ε⁽⁰⁾‖

(стрелка на скане указывает на ‖αᵏ‖ · ‖ε⁽⁰⁾‖: «условие согласованности нормы матрицы и вектора»)

Если ‖α‖ < 1, то при любом векторе начальной погрешности (при любом начальном векторе x⁽⁰⁾) норма погрешности ‖ε⁽ᵏ⁾‖ стремится к нулю не медленнее геометрической прогрессии со знаменателем q ≤ ‖α‖. ◼

Простейшим и распространённым способом приведения системы Ax = b к виду (\*\*), удобному для итераций, является выделение диагональных элементов, при этом каждое i-ое уравнение разрешается относительно i-ого неизвестного

  aᵢᵢ xᵢ = [ bᵢ − Σⱼ₌₁, ᵢ≠ⱼ ⁿ aᵢⱼ xⱼ ],  i = 1, 2, …, n

и метод простой итерации записан в виде

  aᵢᵢ xᵢ⁽ᵏ⁺¹⁾ = [ bᵢ − Σⱼ₌₁, ᵢ≠ⱼ ⁿ aᵢⱼ xⱼ⁽ᵏ⁾ ]

(в конспекте в левых частях обеих формул коэффициент записан как aᵢᵢ / aᵢⱼ нечётко) ⚠

Матрица α при этом имеет вид

```
( 0        −a₁₂/a₁₁   −a₁₃/a₁₁   …   −a₁ₙ/a₁₁ )
( −a₂₁/a₂₂   0        −a₂₃/a₂₂   …   −a₂ₙ/a₂₂ )
( …                                            )
( −aₙ₁/aₙₙ  −aₙ₂/aₙₙ  −aₙ₃/aₙₙ   …      0     )
```

Необходимым и достаточным условием сходимости метода простой итерации является условие того, что целая часть |λₘₐₓ| < 1, где λₘₐₓ — максимальное по модулю собственное значение матрицы α.   ⚠ (на скане «матрицы А»; обозначение и слова «целая часть» читаются нечётко)

← это условие редко используется в практике.

### Теорема

Если какая-либо норма матрицы α, согласованная с рассматриваемой нормой вектора x, меньше единицы (‖α‖ < 1), то имеет место следующая оценка погрешности:

  ‖ε⁽ᵏ⁾‖ ≤ ‖α‖/(1 − ‖α‖) · ‖x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾‖

где ‖x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾‖ — разность соседних приближений.

**Док-во.** ▶ Вычтем из x\* = αx\* + β равенство x⁽ᵏ⁾ = αx⁽ᵏ⁻¹⁾ + β:   ⚠ (на скане в левой части «x⁽ᵏ⁺¹⁾ = αx⁽ᵏ⁾ + β»)

  x\* − x⁽ᵏ⁾ = α[x\* − x⁽ᵏ⁻¹⁾]

  ↓ (−x⁽ᵏ⁻¹⁾)

  x\* − x⁽ᵏ⁻¹⁾ = [x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾] + α[x\* − x⁽ᵏ⁻¹⁾]

Перейдя к нормам, получим:

  ‖ε⁽ᵏ⁻¹⁾‖ ≤ ‖x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾‖ + ‖α‖ ‖ε⁽ᵏ⁻¹⁾‖

или

  [1 − ‖α‖] · ‖ε⁽ᵏ⁻¹⁾‖ ≤ ‖x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾‖

Т.к. по условию 1 − ‖α‖ > 0, то

  ‖ε⁽ᵏ⁻¹⁾‖ ≤ 1/(1 − ‖α‖) · ‖x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾‖

Используя соотношение ε⁽ᵏ⁾ = αε⁽ᵏ⁻¹⁾, получим

  ‖ε⁽ᵏ⁾‖ ≤ ‖α‖/(1 − ‖α‖) · ‖x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾‖  ◼

### Теорема

Если какая-либо норма матрицы α, согласованная с рассматриваемой нормой вектора x, меньше единицы (‖α‖ < 1), то имеет место следующая оценка погрешности:

  ‖ε⁽ᵏ⁾‖ ≤ ‖α‖ᵏ · ‖x⁽⁰⁾‖ + ‖α‖ᵏ/(1 − ‖α‖) · ‖β‖

Погрешности последовательных итераций связаны соотношением

  ‖ε⁽ᵏ⁺¹⁾‖ = ‖α‖ · ‖ε⁽ᵏ⁾‖

т.е. погрешность изменяется на шаге линейно.
Говорят, что метод имеет **линейную сходимость** или **первый порядок сходимости**.
