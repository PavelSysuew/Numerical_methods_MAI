## Страница 1

ЛК-3

Тема: Методы решения нелинейных уравнений и систем нелинейных уравнений.

① Постановка задачи.

Требуется решить нелинейное уравнение

f(x) = 0,

то есть найти такое число x\*, что f(x\*) = 0. Точную формулу для корня, как правило, получить нельзя, поэтому корень ищут итерационно: строят последовательность приближений

1. Выбираем начальное приближение x⁰ и считаем невязку ε⁰ = |f(x⁰)|
2. Строим следующее приближение x¹, считаем ε¹ = |f(x¹)|. Хотим, чтобы ε¹ < ε⁰.
4. Повторяем x⁰, x¹, x², …, xⁿ, … [sic: нумерация пунктов 1, 2, 4, пункта 3 нет]

Невязка — это насколько найденное приближение не удовлетворяет уравнению

Цель: получить такое приближение x′ = xⁿ, что |f(xⁿ)| < ε, где ε > 0 задаётся изначально. Обычно ε берут от 10⁻⁵ до 10⁻¹⁰

## Страница 3

Произвольный случай

В общем случае график f(x) может пересекать ось много раз, функция может быть монотонной или немонотонной. Чтобы искать корни по одному, каждый из них нужно сначала заключить в свой отрезок [a₁, b₁], [a₂, b₂], …

[Рисунок: оси x, y, точка 0; волнообразная кривая пересекает ось Ox в четырёх точках (отмечены точками); на оси жирно выделены отрезки [a₁, b₁] и [a₂, b₂], от их концов пунктирные вертикали; подписаны a₁, b₁, a₂, b₂.]

Две задачи:
1. Найти отрезок, на котором корень единственный (отделение корня)
2. Найти сам корень на этом отрезке с заданной точностью (уточнение корня)

② Отделение корня уравнения

Теорема 1: Если f(x) непрерывна на [a, b] и f(a)·f(b) < 0 (на концах отрезка разный знак), то на [a, b] содержится по крайней мере один корень уравнения f(x) = 0

## Страница 4

Теорема 2: Если f(x) непрерывна и дифференцируема на [a, b], f(a)·f(b) < 0 и f′(x) при x ∈ [a, b] сохраняет знак, то на отрезке [a, b] содержится ровно один корень уравнения f(x) = 0

③ Метод половинного деления (дихотомии)

Пусть f(x) непрерывна и отрезок [a, b] такой, что f(a)·f(b) < 0 (на концах функция меняет знак). Будем сужать интервал существования корня.
1. Находим середину: x¹ = (a + b) / 2
2. Вычисляем произведения f(a)·f(x₁) и f(b)·f(x₁)
3. Выбираем ту половину, на которой произведение отрицательно, и обозначаем её [a¹, b¹]
Повторяем для неё и т.д.

Оценка погрешности

εᵏ = |x\* − xᵏ| ≤ |bᵏ − aᵏ| ≤ |b − a| / 2ᵏ

Чтобы получить точность ε, нужно k ≥ log₂ ((b − a) / ε)

Недостаток: большое число итераций (медленная, линейная сходимость: каждый шаг даёт ровно один двоичный разряд)

## Страница 5

④ Метод простой итерации

Уравнение f(x) = 0 приводим к равносильному виду

f(x) = 0  ⇒  x = φ(x)

Итерационная формула   xⁿ⁺¹ = φ(xⁿ)

Условие сходимости

|φ′(x)| < 1  ∀x ∈ [a, b]

Тогда итерационный процесс сходится к искомому корню

Пример: x³ − x + 1 = 0

Способ 1   x = x³ + 1

xⁿ⁺¹ = (xⁿ)³ + 1,  φ(x) = x³ + 1,  φ′(x) = 3x²

Способ 2
Можно построить последовательность по-другому
x³ = x − 1, откуда x = ∛(x − 1)

xⁿ⁺¹ = ∛(xⁿ − 1),  φ(x) = ∛(x − 1),  φ′(x) = 1 / (3(x − 1)^(2/3))

## Страница 7

⑤ Метод Ньютона (метод касательных)

Пусть xᵏ — текущее приближение к корню x\*, f′(x\*) = 0 [sic: на листе f′(x\*) = 0 вместо f(x\*) = 0]. Разложим f в окрестности xᵏ и оставим линейную часть, а значение в следующей точке приравняем к нулю

f(xᵏ⁺¹) ≈ f(xᵏ) + (df/dx)ₓ₌ₓᵏ · (xᵏ⁺¹ − xᵏ) = 0

Метод Ньютона решения нелинейного уравнения

(в рамке)  xᵏ⁺¹ = xᵏ − f(xᵏ) / (df/dx)ₓ₌ₓᵏ = xᵏ − f(xᵏ) / f′(xᵏ)

Метод Ньютона — частный случай простой итерации с функцией

φ(x) = x − f(x) / f′(x)

В методе простой итерации есть свойство |φ′(x)| < 1. Для метода Ньютона

φ′(x) = f(x)·f″(x) / (f′(x))²

## Страница 8

Геометрический смысл

В точке (x⁰, f(x⁰)) проводим касательную к графику; точка её пересечения с осью Ox — это x¹. В точке (x¹, f(x¹)) снова проводим касательную, получаем x², затем x³. Приближения быстро подходят к корню

[Рисунок: оси x, f(x), точка 0; возрастающая выпуклая вниз кривая y = f(x) (подписана), пересекает ось Ox левее x³ и ось Oy ниже нуля; на оси Ox справа налево точки x⁰, x¹, x², x³; из x⁰ пунктир вверх к кривой, из этой точки касательная к оси в x¹, дальше от x¹ пунктир вверх и касательная в x², затем в x³.]

⑥ Модификация метода Ньютона

Метод Ньютона может «выстрелить» далеко за пределы отрезка, где лежит корень (если касательная пологая). Модификации не дают приближению уйти с отрезка [a, b], на котором мы имеем корень

Способ 1. Коэффициент шага
Вводится коэффициент α, |α| < 1:

xᵏ⁺¹ = xᵏ − α f(xᵏ) / f′(xᵏ)

## Страница 9

Если xᵏ ∈ [a, b], а обычный шаг Ньютона дал xᵏ⁺¹ ∉ [a, b], подбираем α так, чтобы xᵏ⁺¹ ∈ [a, b]

Способ 2. Метод Ньютона + половинное деление (МН и ПД)

Если xᵏ ∈ [a, b], а шаг Ньютона дал xᵏ⁺¹ ∉ [a, b], например xᵏ⁺¹ > b, то вместо него берём середину между текущей точкой и границей

xᵏ⁺¹ = (xᵏ + b) / 2

Аналогично при xᵏ⁺¹ < a берём

xᵏ⁺¹ = (xᵏ + a) / 2

## Страница 10

Матрица Якоби
Матрица частных производных

J(x) = ( ∂f₁(x)/∂x₁ … ∂f₁(x)/∂xₙ
         ⋮          ⋱  ⋮
         ∂fₙ(x)/∂x₁ … ∂fₙ(x)/∂xₙ )

Метод Ньютона для систем

x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − J⁻¹(x⁽ᵏ⁾) f(x⁽ᵏ⁾),  k = 0, 1, 2, …

Критерий остановки

‖x⁽ᵏ⁺¹⁾ − x⁽ᵏ⁾‖ < ε

что эквивалентно (на практике используется как равноценный [?] критерий)

|fᵢ(x̄)| < εᵢ,  i = 1, n

Иногда вводится параметр α (демпфированный метод Ньютона)

x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − α J⁻¹(x⁽ᵏ⁾) f(x⁽ᵏ⁾),  0 < α < 1
