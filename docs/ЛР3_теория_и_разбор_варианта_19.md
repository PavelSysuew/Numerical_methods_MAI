# Часть 0. Общая идея: интерполяция и приближение

Во всей лабораторной функция известна только **таблицей**: в точках x₀, x₁, …, xₙ (их называют **узлами**) даны значения y₀, y₁, …, yₙ. Между узлами функция неизвестна. Задача — заменить её простой функцией (обычно многочленом), с которой можно работать: вычислять в любой точке, дифференцировать, интегрировать.

Два подхода:

| | Интерполяция (3.1, 3.2) | Приближение (аппроксимация) МНК (3.3) |
|---|---|---|
| Условие | функция **точно проходит через все узлы**: P(xᵢ) = yᵢ | функция проходит **близко** к точкам: сумма квадратов отклонений минимальна |
| Степень многочлена | n (на 1 меньше числа узлов) | любая, обычно маленькая (1, 2) |
| Когда применять | данные точные (таблица значений функции) | данные с погрешностью (измерения), или нужна простая формула |

3.4 и 3.5 используют интерполяцию: производную и интеграл берут **от интерполяционного многочлена** вместо неизвестной функции.

# Часть 1. Задание 3.1 — многочлены Лагранжа и Ньютона

## 1.1. Постановка

Даны n + 1 узлов x₀, …, xₙ (все различны) и значения fᵢ = f(xᵢ). Нужен многочлен Pₙ(x) степени не выше n, такой что

> **Pₙ(xᵢ) = fᵢ, i = 0, …, n.**

**Теорема.** Такой многочлен существует и **единственен**.

*Почему единственен:* если бы было два таких многочлена, их разность — многочлен степени ≤ n, обращающийся в ноль в n + 1 точках. У ненулевого многочлена степени n не больше n корней, значит разность тождественно равна нулю.

**Важное следствие:** многочлены Лагранжа и Ньютона — это **один и тот же многочлен**, только записанный по-разному. Программа проверяет это: |L(X\*) − P(X\*)| ≈ 10⁻¹⁶, то есть отличие на уровне ошибок округления.

## 1.2. Многочлен Лагранжа

**Идея.** Строим для каждого узла i «базисный» многочлен lᵢ(x), который равен 1 в узле xᵢ и 0 во всех остальных узлах:

lᵢ(x) = Π_(j≠i) (x − xⱼ)/(xᵢ − xⱼ).

- В узле xⱼ (j ≠ i) один из множителей числителя равен нулю, поэтому lᵢ(xⱼ) = 0.
- В узле xᵢ числитель и знаменатель совпадают, поэтому lᵢ(xᵢ) = 1.

Тогда

> **L(x) = Σᵢ fᵢ · lᵢ(x) = Σᵢ fᵢ · Π_(j≠i) (x − xⱼ)/(xᵢ − xⱼ)**

в каждом узле xₖ даёт fₖ·1 + остальные·0 = fₖ.

**Запись через ω.** Обозначим ω(x) = (x − x₀)(x − x₁)…(x − xₙ). Тогда знаменатель Π_(j≠i)(xᵢ − xⱼ) = ω′(xᵢ), а числитель Π_(j≠i)(x − xⱼ) = ω(x)/(x − xᵢ):

> **L(x) = Σᵢ fᵢ/ω′(xᵢ) · ω(x)/(x − xᵢ)**

Эта запись удобна для ручного счёта: таблица со столбцами xᵢ, fᵢ, ω′(xᵢ), fᵢ/ω′(xᵢ), X\* − xᵢ. Программа выводит ровно такую таблицу.

**Недостаток:** если добавить новый узел, все слагаемые надо пересчитывать заново.

## 1.3. Многочлен Ньютона

**Разделённые разности:**

- нулевого порядка: f(xᵢ) = fᵢ;
- первого порядка: f(xᵢ, xᵢ₊₁) = (fᵢ₊₁ − fᵢ)/(xᵢ₊₁ − xᵢ) — наклон хорды;
- второго порядка: f(xᵢ, xᵢ₊₁, xᵢ₊₂) = [f(xᵢ₊₁, xᵢ₊₂) − f(xᵢ, xᵢ₊₁)]/(xᵢ₊₂ − xᵢ);
- k-го порядка: разность двух соседних разностей (k−1)-го порядка, делённая на расстояние между крайними узлами.

Их записывают «треугольной» таблицей: каждый следующий столбец короче предыдущего на 1.

**Многочлен Ньютона:**

> **P(x) = f(x₀) + f(x₀, x₁)(x − x₀) + f(x₀, x₁, x₂)(x − x₀)(x − x₁) + … + f(x₀, …, xₙ)(x − x₀)…(x − xₙ₋₁)**

Коэффициенты — **верхняя строка** таблицы разделённых разностей.

**Почему он проходит через узлы.** Подставим x = x₀: все слагаемые кроме первого содержат (x − x₀) = 0, остаётся f(x₀). Подставим x = x₁: f(x₀) + f(x₀, x₁)(x₁ − x₀) = f(x₀) + (f₁ − f₀) = f₁. И так далее.

**Достоинство:** при добавлении узла xₙ₊₁ добавляется **одно слагаемое**, а старые не меняются. Поэтому многочлен Ньютона удобнее в программах.

Вычисление в программе: накапливаем произведение (x − x₀)(x − x₁)… по одному множителю, на каждом шаге добавляем «коэффициент · произведение». Это n умножений, а не n² (как у Лагранжа).

## 1.4. Погрешность интерполяции

**Теоретическая оценка.** Если f имеет n + 1 непрерывную производную, то

> **f(x) − Pₙ(x) = f⁽ⁿ⁺¹⁾(ξ)/(n + 1)! · ω(x)**, ξ — некоторая точка между узлами,

отсюда |f(x) − Pₙ(x)| ≤ M₍ₙ₊₁₎/(n + 1)! · |ω(x)|, где M₍ₙ₊₁₎ = max |f⁽ⁿ⁺¹⁾|.

Из формулы видно:
- в узлах ω = 0 — погрешность ноль;
- погрешность пропорциональна |ω(x)|: она тем меньше, чем **ближе узлы к точке x**;
- вне отрезка с узлами (экстраполяция) |ω| быстро растёт.

**Фактическая погрешность** (её и просят «вычислить» в задании): функция известна, поэтому считаем

> **Δ = |L(X\*) − y(X\*)|**.

# Часть 2. Задание 3.2 — кубический сплайн

## 2.1. Зачем сплайны

Один многочлен высокой степени через много узлов плохо себя ведёт: между узлами возникают сильные колебания, особенно у краёв (это видно по росту ω(x)). Решение — **кусочная** интерполяция: на каждом отрезке [xⱼ, xⱼ₊₁] свой многочлен низкой степени, а на стыках они гладко склеиваются.

**Кубический сплайн** — на каждом отрезке многочлен третьей степени, и в узлах непрерывны сама функция, первая и вторая производные. Название от английского spline — гибкая линейка чертёжника: она изгибается так, чтобы энергия изгиба была минимальной, и форма получается как раз кубической.

## 2.2. Вывод системы

На отрезке [xⱼ, xⱼ₊₁] (j = 0, …, n − 1) ищем

> **S(x) = aⱼ + bⱼ(x − xⱼ) + cⱼ(x − xⱼ)² + dⱼ(x − xⱼ)³.**

Обозначим hⱼ = xⱼ₊₁ − xⱼ. Неизвестных 4n: (aⱼ, bⱼ, cⱼ, dⱼ) на каждом из n отрезков.

**Условия:**

1. Интерполяция на левом конце отрезка: S(xⱼ) = fⱼ ⇒ **aⱼ = fⱼ** (n условий).
2. Интерполяция на правом конце: aⱼ + bⱼhⱼ + cⱼhⱼ² + dⱼhⱼ³ = fⱼ₊₁ (n условий).
3. Непрерывность S′ во внутренних узлах (n − 1 условие).
4. Непрерывность S″ во внутренних узлах (n − 1 условие).
5. Два краевых условия. В задании — **нулевая кривизна** на концах: S″(x₀) = 0 и S″(xₙ) = 0 («естественный» сплайн).

Итого 4n условий на 4n неизвестных.

**Сведение к системе для c.** S″(x) = 2cⱼ + 6dⱼ(x − xⱼ), поэтому S″(xⱼ) = 2cⱼ. Удобно ввести ещё cₙ := S″(xₙ)/2 = 0. Тогда:

- из непрерывности S″ в узле xⱼ₊₁: 2cⱼ + 6dⱼhⱼ = 2cⱼ₊₁ ⇒ **dⱼ = (cⱼ₊₁ − cⱼ)/(3hⱼ)**;
- из условия 2: **bⱼ = (fⱼ₊₁ − fⱼ)/hⱼ − hⱼ(cⱼ₊₁ + 2cⱼ)/3**;
- подставляя b и d в непрерывность S′, после преобразований получаем для каждого внутреннего узла j = 1, …, n − 1:

> **hⱼ₋₁cⱼ₋₁ + 2(hⱼ₋₁ + hⱼ)cⱼ + hⱼcⱼ₊₁ = 3[(fⱼ₊₁ − fⱼ)/hⱼ − (fⱼ − fⱼ₋₁)/hⱼ₋₁]**

- краевые условия: **c₀ = 0** (S″(x₀) = 2c₀ = 0) и **cₙ = 0**.

Это система из n − 1 уравнения на c₁, …, cₙ₋₁. **Матрица трёхдиагональная**: в каждом уравнении только cⱼ₋₁, cⱼ, cⱼ₊₁. В первом уравнении c₀ = 0 выпадает, в последнем cₙ = 0 выпадает. Поэтому система решается **методом прогонки из ЛР 1.2**.

Прогонка здесь устойчива: у матрицы **диагональное преобладание**, ведь 2(hⱼ₋₁ + hⱼ) > hⱼ₋₁ + hⱼ.

**Алгоритм:**
1. посчитать hⱼ;
2. составить и решить прогонкой систему для c₁, …, cₙ₋₁;
3. aⱼ = fⱼ, затем bⱼ и dⱼ по формулам выше;
4. для X\* найти отрезок, которому он принадлежит, и вычислить S(X\*).

# Часть 3. Задание 3.3 — метод наименьших квадратов

## 3.1. Постановка

Даны N + 1 точек (xₖ, yₖ). Ищем многочлен **невысокой** степени m

F(x) = a₀ + a₁x + … + aₘxᵐ

(m намного меньше числа точек), который **проходит близко** к точкам. Через все точки он пройти не может: уравнений больше, чем неизвестных.

«Близко» понимают в смысле **суммы квадратов ошибок**:

> **Φ(a₀, …, aₘ) = Σₖ (F(xₖ) − yₖ)² → min**

Почему квадраты: они не дают положительным и отрицательным ошибкам компенсировать друг друга, сильнее штрафуют большие отклонения и, главное, приводят к **линейной** системе.

## 3.2. Нормальная система

Φ — гладкая функция коэффициентов, в минимуме все частные производные равны нулю:

∂Φ/∂aᵢ = 2 Σₖ (F(xₖ) − yₖ) · xₖⁱ = 0, i = 0, …, m.

Подставляя F(xₖ) = Σⱼ aⱼxₖʲ, получаем

> **Σⱼ aⱼ · (Σₖ xₖ^(i+j)) = Σₖ yₖ · xₖⁱ, i = 0, …, m**

— **нормальную систему МНК**: m + 1 линейное уравнение на m + 1 неизвестное. Матрица симметричная, её элемент (i, j) — сумма степеней xₖ^(i+j).

**Для m = 1** (прямая a₀ + a₁x):

```
⎧ (N+1)·a₀ + Σx·a₁   = Σy
⎩ Σx·a₀    + Σx²·a₁  = Σxy
```

**Для m = 2** (парабола):

```
⎧ (N+1)·a₀ + Σx·a₁  + Σx²·a₂ = Σy
⎨ Σx·a₀    + Σx²·a₁ + Σx³·a₂ = Σxy
⎩ Σx²·a₀   + Σx³·a₁ + Σx⁴·a₂ = Σx²y
```

В программе нормальная система решается **LU-разложением из ЛР 1.1**.

**Если m = N** (степень на 1 меньше числа точек), МНК даёт интерполяционный многочлен, и Φ = 0.

## 3.3. Ошибка MSE

По требованиям многочлены сравниваются по **среднеквадратичной ошибке** (mean squared error):

> **MSE = Φ/N = (1/N)·Σₖ (P(xₖ) − yₖ)²**, N — число точек.

Это та же сумма квадратов ошибок, только делённая на число точек: средний квадрат отклонения. Минимизировать MSE и Φ — одно и то же (они отличаются постоянным множителем), поэтому нормальная система не меняется. MSE удобнее для сравнения таблиц с разным числом точек.

# Часть 4. Задание 3.4 — численное дифференцирование

## 4.1. Идея

Производную от таблично заданной функции берут как **производную интерполяционного многочлена**, построенного по нескольким соседним узлам.

## 4.2. Формулы

Обозначим Δᵢ = (yᵢ₊₁ − yᵢ)/(xᵢ₊₁ − xᵢ) — наклон хорды на [xᵢ, xᵢ₊₁] (разделённая разность первого порядка).

**Первая производная, первый порядок точности** — по двум узлам (производная прямой через них):

> **y′(x) ≈ Δᵢ, x ∈ [xᵢ, xᵢ₊₁]**

Если x совпадает с узлом xᵢ, можно взять отрезок слева или справа:
- **левая разность:** (yᵢ − yᵢ₋₁)/h;
- **правая разность:** (yᵢ₊₁ − yᵢ)/h.

Погрешность O(h): при уменьшении шага вдвое ошибка уменьшается примерно вдвое.

**Первая производная, второй порядок точности** — по трём узлам xᵢ, xᵢ₊₁, xᵢ₊₂, как производная параболы (многочлена Ньютона второй степени):

P₂(x) = yᵢ + Δᵢ(x − xᵢ) + (Δᵢ₊₁ − Δᵢ)/(xᵢ₊₂ − xᵢ) · (x − xᵢ)(x − xᵢ₊₁)

> **y′(x) ≈ Δᵢ + (Δᵢ₊₁ − Δᵢ)/(xᵢ₊₂ − xᵢ) · (2x − xᵢ − xᵢ₊₁)**

Погрешность O(h²): при уменьшении шага вдвое ошибка уменьшается примерно вчетверо.

**Вторая производная** — вторая производная той же параболы (она постоянна):

> **y″(x) ≈ 2(Δᵢ₊₁ − Δᵢ)/(xᵢ₊₂ − xᵢ)**

**Частный случай равномерной сетки и x = xᵢ₊₁ (средний узел)**: получаются известные центральные формулы

y′ ≈ (yᵢ₊₂ − yᵢ)/(2h),  y″ ≈ (yᵢ₊₂ − 2yᵢ₊₁ + yᵢ)/h².

Центральная разность равна среднему арифметическому левой и правой.

**Выбор узлов для параболы в программе:**
- если X\* — внутренний узел, парабола строится по этому узлу и двум соседям (симметрично);
- если X\* между узлами, берётся отрезок с X\* и следующий узел (у правого края — предыдущий).

- левая разность: Δ₁ = (1.7854 − 0)/1 = **1.7854**;
- правая разность: Δ₂ = (3.1071 − 1.7854)/1 = **1.3217**.

**Второй порядок** (парабола по x₁ = 0, x₂ = 1, x₃ = 2):

# Часть 5. Задание 3.5 — численное интегрирование

## 5.1. Идея

Отрезок [X₀, Xₖ] делим на N частей с шагом h (узлы xᵢ = X₀ + ih, yᵢ = f(xᵢ)). На каждой части заменяем функцию простым многочленом и интегрируем его точно.

## 5.2. Формулы

**Методы прямоугольников.** На каждом отрезке [xᵢ₋₁, xᵢ] функция заменяется константой, и площадь под ней — прямоугольник высотой в эту константу. Методы отличаются тем, где взять высоту:

> **левые:  F ≈ h · (y₀ + y₁ + … + y_(N−1))** — значение в левом конце отрезка
>
> **правые: F ≈ h · (y₁ + y₂ + … + y_N)** — значение в правом конце
>
> **средние: F ≈ h · Σᵢ f(xᵢ₋₁ + h/2)** — значение в середине отрезка

Левые и правые прямоугольники используют только узлы сетки, средние требуют значений в серединах отрезков.

**Метод трапеций.** На каждом отрезке — прямая через концы (площадь трапеции):

> **F ≈ h · (y₀/2 + y₁ + y₂ + … + y_(N−1) + y_N/2)**

**Метод Симпсона.** На каждой паре соседних отрезков — парабола через три узла. Поэтому **N должно быть чётным**:

> **F ≈ h/3 · (y₀ + 4y₁ + 2y₂ + 4y₃ + … + 2y_(N−2) + 4y_(N−1) + y_N)**

Коэффициенты: на концах 1, в нечётных узлах 4, в чётных внутренних 2.

**Порядки точности:**

| Метод | Чем заменяем f на отрезке | Погрешность F − F_h | p |
|---|---|---|---|
| Левые прямоугольники | константой f(xᵢ₋₁) | ≈ (b − a)·h·f′/2 | 1 |
| Правые прямоугольники | константой f(xᵢ) | ≈ −(b − a)·h·f′/2 | 1 |
| Средние прямоугольники | константой f(середины) | ≈ (b − a)·h²·f″/24 | 2 |
| Трапеции | прямой | ≈ −(b − a)·h²·f″/12 | 2 |
| Симпсон | параболой | ≈ −(b − a)·h⁴·f⁽⁴⁾/180 | 4 |

Из таблицы видно:
- у левых и правых прямоугольников порядок **первый**: ошибка пропорциональна h, а не h². Причина — несимметричность: высота берётся на краю отрезка, и если функция растёт, левые прямоугольники систематически занижают площадь, правые завышают;
- в середине отрезка линейная часть ошибки сокращается (половина отрезка выше, половина ниже), поэтому средние прямоугольники сразу получают второй порядок;
- ошибка средних прямоугольников примерно **вдвое меньше** ошибки трапеций и **противоположна по знаку**. Метод Симпсона точен для многочленов до третьей степени включительно.

## 5.3. Метод Рунге–Ромберга

Пусть метод имеет порядок p: F ≈ F_h + C·hᵖ, где C почти не зависит от h. Посчитаем интеграл с двумя шагами: h и kh (у нас h = h₂ = 0.5, kh = h₁ = 1, k = 2):

F = F_h + C·hᵖ,
F = F_kh + C·(kh)ᵖ.

Вычитая, находим C·hᵖ = (F_h − F_kh)/(kᵖ − 1). Отсюда:

> **уточнённое значение: F ≈ F_h + (F_h − F_kh)/(kᵖ − 1)**
>
> **оценка погрешности F_h: |F_h − F_kh|/(kᵖ − 1)**

Смысл: по тому, как изменился результат при уменьшении шага, оцениваем, сколько ещё осталось до точного значения, и добавляем эту поправку. Точное значение интеграла при этом **не нужно**.

## 5.5. Проверка по точному значению

Интеграл берётся аналитически (это только для проверки, программа методов от этого не зависит):

x²/(625 − x⁴) = x²/((25 − x²)(25 + x²)) = ½·[1/(25 − x²) − 1/(25 + x²)],

первообразная (1/20)·ln((5 + x)/(5 − x)) − (1/10)·arctg(x/5), поэтому

**F = (1/20)·ln 9 − (1/10)·arctg 0.8 = 0.0423871**.

## 5.6. Анализ

0. **Наиболее точный метод — Симпсон:** с шагом h₂ погрешность 7.1·10⁻⁵, после уточнения Рунге–Ромберга 3.3·10⁻⁵. Хуже всех — левые и правые прямоугольники (первый порядок).
1. **Оценка Рунге–Ромберга работает:** для средних прямоугольников и трапеций она (4.6·10⁻⁴, 9.8·10⁻⁴) почти совпадает с настоящей ошибкой при h₂ (5.2·10⁻⁴, 1.1·10⁻³).
2. **Уточнение резко повышает точность:** у средних прямоугольников ошибка уменьшилась в 9 раз, у трапеций — в 15 раз.
3. **Порядок виден по числам:** при уменьшении шага вдвое ошибка левых и правых прямоугольников уменьшилась в 1.8–2.2 раза (теория: 2¹ = 2), средних прямоугольников и трапеций — в 3.7–3.8 раза (теория: 2² = 4). У Симпсона — в 9 раз вместо теоретических 2⁴ = 16: шаг ещё великоват для этой функции, она резко растёт к x = 4 (f⁽⁴⁾ там большая), асимптотика ещё не наступила. Поэтому и оценка Рунге–Ромберга для Симпсона (3.8·10⁻⁵) занижена по сравнению с настоящей ошибкой (7.1·10⁻⁵).
4. **Ошибки средних прямоугольников и трапеций противоположны по знаку** (средние прямоугольники дают меньше точного, трапеции — больше) и отличаются примерно вдвое, как и предсказывает теория: функция выпукла вниз, и хорды трапеций лежат выше графика. Левые прямоугольники дают сильно меньше точного, правые — сильно больше: функция возрастает.
5. **Интересный факт:** уточнение Рунге–Ромберга для трапеций (0.0424576625) **в точности равно** методу Симпсона с шагом h₂. Это не случайность: формула Симпсона алгебраически получается из двух формул трапеций, (4T_h − T₂h)/3. Так что Симпсон — это «трапеции, уточнённые по Рунге».
6. **Ещё один точный факт:** уточнение Рунге–Ромберга для левых **и** правых прямоугольников (p = 1) дало ровно 0.0404890 — значение **средних** прямоугольников с шагом h₁. Почему: левые с шагом h/2 берут левые концы половинок, то есть старые левые узлы и середины старых отрезков, поэтому L_(h/2) = (L_h + M_h)/2, где M_h — средние прямоугольники. Тогда уточнение L_(h/2) + (L_(h/2) − L_h)/(2¹ − 1) = 2L_(h/2) − L_h = M_h. Для правых аналогично. Рунге–Ромберг убрал ошибку первого порядка, и получился метод второго порядка.

# Часть 7. Вопросы на сдаче

**Интерполяция (3.1)**

1. *Что такое интерполяция?* — Построение функции (многочлена), которая точно проходит через заданные узлы.
2. *Почему многочлен Лагранжа и Ньютона дают одинаковое значение?* — Интерполяционный многочлен степени n по n + 1 узлам единственен; это две записи одного многочлена.
3. *Чем Ньютон удобнее Лагранжа?* — При добавлении узла добавляется одно слагаемое, остальные не пересчитываются. Вычисление быстрее.
4. *Что такое разделённая разность?* — Обобщение наклона хорды: f(xᵢ, xᵢ₊₁) = (fᵢ₊₁ − fᵢ)/(xᵢ₊₁ − xᵢ), высшие — рекурсивно.
5. *От чего зависит погрешность интерполяции?* — От (n+1)-й производной и от ω(x) = Π(x − xᵢ): она мала, когда узлы близко к точке.
6. *Почему в наборе б) погрешность меньше?* — |ω(0.1)| = 0.002 против 0.004: узел 0 ближе к X\* = 0.1, чем −0.1.
7. *Что будет, если два узла совпадут?* — Деление на ноль в ω′(xᵢ) и в разделённых разностях; программа проверяет, что узлы различны.

**Сплайн (3.2)**

8. *Что такое кубический сплайн?* — Кусочно-кубическая функция, непрерывная вместе с первой и второй производными.
9. *Зачем сплайн, если есть многочлен Лагранжа?* — Многочлен высокой степени по многим узлам сильно колеблется; сплайн гладкий и устойчивый при любом числе узлов.
10. *Сколько неизвестных и условий?* — 4n неизвестных; условия: 2n интерполяционных, n − 1 на S′, n − 1 на S″, 2 краевых.
11. *Что значит «нулевая кривизна на концах»?* — S″(x₀) = S″(xₙ) = 0, отсюда c₀ = cₙ = 0.
12. *Почему система для c решается прогонкой? Устойчива ли прогонка?* — Матрица трёхдиагональная; диагональное преобладание 2(h + h) > h + h гарантирует устойчивость.
13. *Почему сплайн здесь менее точен, чем многочлен 3.1?* — Истинная кривизна на концах не нулевая (−0.52 и 3.70), а сплайн её обнуляет.

**МНК (3.3)**

14. *Чем МНК отличается от интерполяции?* — Многочлен не проходит через точки, а минимизирует сумму квадратов отклонений; степень меньше числа точек.
15. *Как получается нормальная система?* — Приравниваем нулю частные производные Φ по коэффициентам.
16. *Почему MSE₃ ≤ MSE₂ ≤ MSE₁?* — Многочлен меньшей степени — частный случай большей (старшие коэффициенты 0), поэтому минимум по более широкому классу не больше.
16а. *Что такое MSE и чем она отличается от Φ?* — MSE = Φ/N, средний квадрат ошибки. Минимизировать их одно и то же; MSE удобнее для сравнения.
16б. *Почему P₂ почти не лучше P₁, а P₃ лучше в 170 раз?* — arcsin x + x = 2x + x³/6 + …: квадратичного члена у функции нет, а кубический есть.
17. *Что будет, если степень = число точек − 1?* — Получится интерполяционный многочлен, Φ = 0.
18. *Чем вы решали нормальную систему?* — Своим LU-разложением из ЛР 1.1.

**Дифференцирование (3.4)**

19. *Откуда берутся формулы численного дифференцирования?* — Дифференцируем интерполяционный многочлен: прямую (1-й порядок) или параболу (2-й порядок).
20. *Что значит «порядок точности»?* — Погрешность пропорциональна hᵖ; при уменьшении h вдвое ошибка уменьшается в 2ᵖ раз.
21. *Почему центральная разность точнее левой и правой?* — Ошибки левой и правой разностей разного знака и почти компенсируются; формула симметрична, первый член ошибки сокращается.
22. *Можно ли брать очень маленький шаг?* — Нет: вычитаются близкие числа, ошибки округления делятся на h и растут. Численное дифференцирование неустойчиво.

**Интегрирование (3.5)**

23. *На чём основаны формулы прямоугольников, трапеций, Симпсона?* — Замена функции на отрезке константой, прямой, параболой и точное интегрирование замены.
24. *Почему для Симпсона нужно чётное число отрезков?* — Парабола строится по трём узлам, то есть на паре соседних отрезков.
25. *Какие порядки точности у методов?* — Левые и правые прямоугольники 1, средние прямоугольники и трапеции 2, Симпсон 4.
25а. *Почему у левых/правых прямоугольников порядок 1, а у средних 2?* — В середине отрезка линейная часть ошибки сокращается (половина отрезка выше, половина ниже); на краю — нет.
25б. *Почему Рунге–Ромберг для левых и правых дал ровно средние прямоугольники с шагом h₁?* — L_(h/2) = (L_h + M_h)/2, поэтому 2L_(h/2) − L_h = M_h (см. п. 5.6).
26. *Как работает метод Рунге–Ромберга?* — По двум расчётам с шагами h и kh оцениваем главный член погрешности C·hᵖ = (F_h − F_kh)/(kᵖ − 1) и добавляем его к F_h.
27. *Почему уточнение трапеций совпало с Симпсоном?* — Формула Симпсона и есть (4T_h − T_2h)/3 — трапеции, уточнённые по Рунге.
28. *Почему ошибка Симпсона уменьшилась в 9 раз, а не в 16?* — Шаг ещё крупный для этой функции (она резко растёт к x = 4), асимптотическая оценка ~h⁴ ещё не выполняется.
