## 1. Главная идея: график — это набор точек

matplotlib не понимает формулы. Он получает два массива — абсциссы и ординаты — и соединяет соседние точки отрезками.

```python
x = np.linspace(0, 2, 5)   # [0.  0.5 1.  1.5 2. ]
y = x**2                   # [0.  0.25 1.  2.25 4. ]
plt.plot(x, y)
plt.show()
```

- `np.linspace(a, b, n)` — `n` равномерно расставленных точек от `a` до `b` (оба конца включены).
- Арифметика над массивом NumPy выполняется поэлементно: `x**2`, `2*x + 1`, `np.exp(x)`, `np.log10(x)` возвращают массив той же длины.
- Если точек мало, кривая получается ломаной. Для гладкого графика берите 300–1000 точек.

Математические функции берите из NumPy, а не из `math`: `math.sin` не принимает массив.

| В математике | В NumPy |
|---|---|
| eˣ | `np.exp(x)` |
| ln x | `np.log(x)` |
| lg x | `np.log10(x)` |
| sin x, cos x, tg x | `np.sin(x)`, `np.cos(x)`, `np.tan(x)` |
| √x | `np.sqrt(x)` |
| \|x\| | `np.abs(x)` |

## 2. `plt.show()` — показать окно

Пока не вызвана `plt.show()`, всё рисуется «в памяти». `show()` открывает окно и **останавливает программу**, пока окно не закроют.

Панель внизу окна:

- 🔍 (лупа) — выделите прямоугольник мышью, и он увеличится. Так ищут корень с точностью до 0.1, 0.01 и т. д.
- ✥ (крестик) — перемещение графика мышью.
- 🏠 (домик) — вернуть исходный масштаб.
- 💾 — сохранить картинку.
- В правом нижнем углу окна видны координаты `x=…, y=…` под курсором мыши.

## 3. Оформление графика

```python
x = np.linspace(-2, 2, 400)

plt.plot(x, x**3 - x + 1, label="y = x³ − x + 1")  # label — подпись для легенды
plt.axhline(0, color="black", linewidth=0.8)      # горизонтальная прямая y = 0 (ось Ox)
plt.axvline(0, color="black", linewidth=0.8)      # вертикальная прямая x = 0 (ось Oy)
plt.xlim(-2, 2)                                   # видимый диапазон по x
plt.ylim(-3, 5)                                   # видимый диапазон по y
plt.xlabel("x")
plt.ylabel("y")
plt.title("Отделение корня")
plt.grid(True)                                    # сетка
plt.legend()                                      # показать подписи из label
plt.show()
```

Зачем нужны `axhline` и `axvline`: matplotlib сам не рисует оси через ноль, а рисует рамку вокруг графика. Чтобы видеть, где кривая пересекает Ox, ось нужно нарисовать самому.

Зачем нужен `ylim`: если функция где-то становится большой (x⁴ при x = 3 равно 81), масштаб подстраивается под неё, и область около нуля сжимается в полоску.

### Параметры линии

```python
plt.plot(x, y, color="red", linestyle="--", linewidth=2, label="...")
```

- `color`: `"red"`, `"blue"`, `"green"`, `"black"`, `"orange"` и т. д.
- `linestyle`: `"-"` сплошная, `"--"` штриховая, `":"` пунктир.
- Короткая запись: `plt.plot(x, y, "r--")` — красная штриховая.

### Отметить точку

```python
plt.plot(1.5, 0, "ro")              # одна красная точка (x=1.5, y=0)
plt.scatter([1, 2], [0, 0], color="red")   # несколько точек
plt.annotate("x⁰", (1.5, 0))        # подпись возле точки
```

### Сетка с нужным шагом

```python
plt.xticks(np.arange(-2, 2.1, 0.5))   # деления по x через 0.5
```

## 4. Несколько графиков на одной картинке

### Несколько кривых на одних осях

Просто вызовите `plt.plot` несколько раз до `plt.show()`:

```python
plt.plot(x, x**3, label="y = x³")
plt.plot(x, x - 1, label="y = x − 1")
plt.legend()
plt.show()
```

Это второй способ отделения корня из ЛК-3 (стр. 2): корень — абсцисса точки пересечения.

### Несколько осей рядом (`subplots`)

```python
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(11, 5))  # 1 строка, 2 столбца; размер в дюймах

ax1.plot(x, x**3 - x + 1)
ax1.set_title("Способ 1")

ax2.plot(x, x**3)
ax2.plot(x, x - 1)
ax2.set_title("Способ 2")

plt.show()
```

При работе через объект осей (`ax`) часть функций называется иначе — с приставкой `set_`:

| `plt.…` | `ax.…` |
|---|---|
| `plt.title` | `ax.set_title` |
| `plt.xlim`, `plt.ylim` | `ax.set_xlim`, `ax.set_ylim` |
| `plt.xlabel`, `plt.ylabel` | `ax.set_xlabel`, `ax.set_ylabel` |
| `plt.plot`, `plt.grid`, `plt.legend`, `plt.axhline` | так же: `ax.plot`, `ax.grid`, … |

## 6. Графики для систем (ЛР 2.2): неявные кривые

Уравнение системы вида f₁(x₁, x₂) = 0 нельзя записать как «y = …» в общем случае. Такую кривую рисуют через `contour` — линию уровня функции двух переменных на уровне 0.

```python
x1 = np.linspace(0.1, 3, 400)
x2 = np.linspace(0.1, 3, 400)
X1, X2 = np.meshgrid(x1, x2)        # сетка: все пары (x1, x2)

F1 = X1**2 + X2**2 - 4              # пример: окружность x1² + x2² = 4
F2 = X1 - X2                        # пример: прямая x1 = x2

plt.contour(X1, X2, F1, levels=[0], colors="blue")   # кривая F1 = 0
plt.contour(X1, X2, F2, levels=[0], colors="red")    # кривая F2 = 0
plt.xlabel("x1")
plt.ylabel("x2")
plt.grid(True)
plt.show()
```

- `np.meshgrid` превращает два одномерных массива в два двумерных: в `X1[i, j]` и `X2[i, j]` лежит точка сетки. Тогда `F1` — значение функции в каждой точке сетки.
- `levels=[0]` — нарисовать только ту линию, где функция равна нулю.
- Решение системы — точка пересечения синей и красной кривых, её координаты и есть начальное приближение (x₁⁰, x₂⁰).
- `contour` не поддерживает `label` для легенды. Цвета кривых подпишите в заголовке: `plt.title("синяя: f1 = 0, красная: f2 = 0")`.

Если в функции есть логарифм или корень, берите сетку только там, где они определены (для `np.log10(X2)` нужно X2 > 0). Иначе NumPy выдаст предупреждение и в этих точках будет `nan`; график всё равно построится, но предупреждение лучше не допускать.

## 7. Частые ошибки

| Что видно | Причина |
|---|---|
| Окно не появилось | Забыли `plt.show()` |
| `TypeError: only length-1 arrays…` | Использовали `math.sin` вместо `np.sin` |
| Кривая ломаная | Мало точек в `linspace` |
| Около нуля ничего не разобрать | Не задан `ylim` |
| Легенда пустая или не появилась | Нет `label=` в `plot` или не вызван `legend()` |
| Сохранённая картинка пустая | `savefig` вызван после `show()` |
| `RuntimeWarning: invalid value in log10` | Сетка захватила точки вне области определения |
